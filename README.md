# Situs Pribadi Bowie

Landing page pribadi — Bahasa Indonesia, tema gelap, satu file HTML tanpa dependensi eksternal.

- **Situs live:** https://netbowie.github.io/
- **Isi:** `index.html` (satu file, self-contained — tanpa CDN, tanpa font eksternal, tanpa JavaScript pihak ketiga)
- **Bagian:** hero, tentang, proyek (Luna · Dashboard Cuaca · Pemantau UPS · Laporan PC), tumpukan, kontak

## Cara memperbarui

```bash
git add -A
git commit -m "perbarui isi halaman"
git push
```

GitHub Pages membangun ulang otomatis setiap kali `main` menerima commit (biasanya < 1 menit).

## Catatan

- Repositori ini publik karena GitHub Pages gratis mensyaratkan repo publik.
- Halaman statis: tidak ada kode server, tidak ada data pribadi selain yang tertulis di halaman.
